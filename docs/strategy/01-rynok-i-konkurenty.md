# 01. Рынок «почта на Nostr» — живые данные

Собрано: 2026-09-10. Источник — GitHub API (звёзды, дата последнего пуша) и HTTP-проверка
доменов; не обзоры и не пресс-релизы (в обзорах, например, `mailstr.com` назван живым,
а он не отвечает вовсе).

## Сколько их вообще

Весь Nostr по теме «mail» — **29 репозиториев**. Это микро-ниша, а не рынок.

Живые домены: **nostrmail.org** (HTTP 200, «Открытый протокол децентрализованной почты»
экосистемы nogringo), **uid.ovh** (HTTP 200 — `npub@uid.ovh` работает сразу, короткое имя
по запросу, вход через расширение/remote signer, «ключи твои, не наши»).
**mailstr.com — HTTP 000, домен мёртв.**

## Что это значит для нас

1. **Формат у всех один и тот же, что у нас**: kind 1301 внутри NIP-59 gift-wrap,
   поиск через NIP-05. Мы не изобретаем стандарт — мы в нём уже находимся:
   наш мост находят их клиенты через `/.well-known/nostr.json`.
2. **Всего один лидер с клиентом.** У nogringo есть клиент, SDK, мост и лендинг.
   У нас клиента нет — и делать его не обязательно: их Nmail открывает наши ящики.
3. **Ни у кого нет почты для агентов** — все делают почту для людей. У нас 23 живых
   ящика, среди них агенты с паспортами (kind 8010 по NIP-80).
4. **Никто не публикует пользовательские цифры** — только звёзды. Значит рынок
   не сформирован и место лидера свободно.
5. **Наш отстающий пункт**: мост в обычную почту у nogringo уже есть (SMTP/Mailgun),
   у нас IMAP отложен до сервера с открытым портом 993.
