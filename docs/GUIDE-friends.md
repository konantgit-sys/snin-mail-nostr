# SNIN Mail — как дать ящик другу

**Домен:** `snin-mail.v2.site` · Обновлено: 2026-08-27

Друг может сам зарегистрировать ящик за 2 минуты, имея **только свой nostr-ключ (nsec)**.
Никакого администрирования с нашей стороны не нужно.

## Что делает друг

1. Открывает `https://snin-mail.v2.site`
2. На странице входа жмёт **«Зарегистрировать ящик»**
3. Вводит:
   - **nsec** — свой nostr-ключ (например, из Amethyst/Primal/алконавта)
   - **Имя/метку** — как его показывать (необязательно)
   - **Пароль** — от ящика на нашем сайте (минимум 6 символов, не путать с nsec)
4. Жмёт «Создать ящик» → получает адрес вида `npub1…@snin-mail.v2.site`
5. Входит с этим адресом и паролем — готово

## Что происходит внутри (механика)

- `POST /api/register`: проверяет nsec (валидность + владение через вывод pubkey),
  пароль (≥6), дубликаты, rate-limit (50 регистраций/час)
- nsec шифруется AES-GCM (keys/master.key) и хранится в `mail_keys` — мосту нужен
  для расшифровки NIP-59 gift wrap
- **Динамически поднимается отдельный мост на ключ друга** (новый поток MailBridge):
  подписка на релеи, расшифровка, квота 500 писем, Telegram-уведомления с меткой друга
- **NIP-05 discovery** отдаёт адрес друга (с 2026-08-27) — его можно показывать
  в профиле как «почту»
- Роль — `user`: видит только свой ящик, без переключения чужих

## Проверено E2E (2026-08-27)

Регистрация → вход → NIP-05 резолвится → отправка → доставка через личный
мост → письма от ВНЕШНИХ клиентов (plain kind:1301) доставляются через
маршрутизацию To:. Полный контур работает. Тестовый аккаунт после проверки удалён.

## Ограничения (честно)

- **Внутри нашей сети** (наш веб-клиент) письма другу ходят идеально
- **Внешние клиенты** (nostrmail.org, Nmail): адрес друга резолвится по NIP-05,
  но письма от внешних клиентов идут через `_smtp` (мост Крайтера) и падают
  в ящик Крайтера. Маршрутизация `To:` между ящиками одного домена —
  следующий шаг (Фаза 3)
- Вложения — через Blossom (NIP-96): файл уходит на snin-mail.v2.site/media/<sha256>, в письме — ссылка. Лимит 20 МБ на файл (было ~33 КБ base64)
